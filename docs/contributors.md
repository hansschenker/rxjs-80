# Contributors

rxjs-80 is developed collaboratively around a shared goal: make RxJS behavior easier to learn through fewer operator names and explicit policy choices.

| Contributor | Contribution |
|---|---|
| **[Hans Schenker](https://github.com/hansschenker)** | Project creator, behavioral vocabulary, API direction, learning approach, and review. |
| **ChatGPT (OpenAI)** | **Main contributor and co-author** of the initial API design, TypeScript implementation, verification suite, learning material, and VitePress operator website, in collaboration with Hans Schenker. |
| **[RxJS contributors](https://github.com/ReactiveX/rxjs/graphs/contributors)** | Observable runtime, schedulers, operator implementations, documentation, and the foundations this facade delegates to. |
| **[VitePress contributors](https://github.com/vuejs/vitepress/graphs/contributors)** | Documentation framework, local search, navigation, and theme infrastructure. |

AI-assisted contributions are acknowledged in repository documentation and commit co-author trailers. GitHub's automatically generated contributor graph may display attribution differently from this explicit contributor list.
