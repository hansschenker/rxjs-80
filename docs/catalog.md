## What counts as 80?

**15 consolidated families + 58 compatibility exports + 7 creation functions.** Configuration helpers such as `withTime` and `withSignal` live in `rxjs-80/controls` and are counted separately. Some compatibility names remain deprecated in RxJS; the catalog preserves them explicitly.

The selected scope represents 113 names from `rxjs/operators` plus seven creation functions. Each family counts once, including all supported variants of `buffer` and `window`. [Read the exact inventory](/OPERATOR-CATALOG).
