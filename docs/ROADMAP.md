# Roadmap

- [x] Exactly 80 root operator/creation exports and a separately counted controls module.
- [x] Consolidate the six boundary families, take/skip, four flattening policies, map, distinct, and sharing.

No npm publication or release tag is automatic. The repository is the initial reviewable project.
